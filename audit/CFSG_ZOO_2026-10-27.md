## 1. Claim and proof target

The project's [README](https://github.com/enuminous/CFSG/tree/69cb972f587a3ecc035e092253167ff2e303c962/README.md) describes a `sorry`-free Lean proof of the classification of finite simple groups, using Lean 4 v4.35.0-rc3 and standard axioms `Classical.choice`, `propext`, and `Quot.sound`. The matching target is:

```lean
theorem CFSGComparator.classification : TauCeti.ClassificationStatement.{u} :=
  TauCeti.classificationStatement_of_zero <|
    TauCeti.classificationStatement_iff.2 fun G _ _ _ =>
      CFSG.Certified.classification_finite_simple_groups G
```

Source: [Comparator/Solution.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/Comparator/Solution.lean). The original finite-simple-group statement appears in [CFSG/Statement.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/CFSG/Statement.lean) and is transported by the wrapper in [CFSG/Certified/Classification.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/CFSG/Certified/Classification.lean). The native-and-realization milestone appears in [CFSG/Milestones/CFSG_classification.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/CFSG/Milestones/CFSG_classification.lean).

**Source-level route observed:** `CFSGComparator.classification` → `CFSG.Certified.classification_finite_simple_groups` → `CFSG.classification_finite_simple_groups` → `Assembly.classification` with supplied subtheorems. The route is real in the inspected text; the soundness and completeness of the full transitive import graph have not been independently checked here.

### Challenge template is not a proof-hole finding

[Comparator/Challenge.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/Comparator/Challenge.lean) literally ends in `:= sorry`, while the separate [Comparator/Solution.lean](https://github.com/enuminous/CFSG/blob/69cb972f587a3ecc035e092253167ff2e303c962/Comparator/Solution.lean) provides an explicit term with no literal `sorry`. The challenge is a stated task template; its presence does not establish a hole in the submitted solution. On the other hand, examining only the solution file does not establish that the entire imported proof is free from unsound declarations.

## 6. Minimal reproducibility procedure

Run these in a clean environment with the **frozen** source revision, adequate disk capacity and the exact pinned Lean/Lake dependencies. Do not edit `lake-manifest.json` without recording changes.

```bash
git clone https://github.com/enuminous/CFSG.git
cd CFSG
git checkout 69cb972f587a3ecc035e092253167ff2e303c962
cat lean-toolchain
lake build
```

After the full build, create an external temporary Lean file (do not modify the proof artifacts) containing:

```lean
import Comparator.Solution
import CFSG.Milestones.CFSG_classification
#print axioms CFSGComparator.classification
#print axioms CFSG.Milestones.cfsg_classification_native_and_realization
```

Run it with the repository's Lake environment and record exact output and environment. The imported modules or Lean module-system behavior may require command adjustments; record any such adjustment rather than presenting an unrun command as a verified reproduction.
